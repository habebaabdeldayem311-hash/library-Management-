# Library Management System

This project is a relational database management system for a library, implemented using SQL. It is designed to efficiently manage books, authors, members, and borrowing operations.

## Project Contents
- `Library Management System.sql`: Contains the database schema (DDL) and sample data (DML).
- `ERD Diagram.png`: A visual representation of the database relationship model.
- `JOIN Query.png`: An example of data retrieval using JOIN operations.

## How to Use
1. Download the `.sql` file.
2. Open your preferred database management tool (e.g., MySQL Workbench, DBeaver, or pgAdmin).
3. Execute the script to create the tables and insert the sample data.

This project was developed to demonstrate skills in database design, relational modeling, and SQL querying.
